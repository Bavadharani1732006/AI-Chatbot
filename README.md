# AI Chatbot

## Overview
AI Chatbot is a web-based chatbot application developed using Python and Flask. It provides an interactive chat interface where users can ask questions and receive automated responses.

## Features
- Interactive chat interface
- Real-time responses
- User-friendly design
- Web-based application
- Easy to customize

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## Project Structure
AI-Chatbot/
│
├── app.py
├── config.py
├── modules/
├── templates/
├── static/
└── README.md

## Installation
1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt

3. Run the application:
   python app.py

4. Open browser:
   http://localhost:5000
